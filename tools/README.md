# Reusable tools

Store reusable tool scripts, not temporary requests, raw outputs, or credentials.
Whenever you add, change, rename, or remove a tool, update this README. For every tool document:

- path and purpose;
- exact invocation;
- inputs, outputs, and side effects;
- runtime and package dependencies;
- one minimal example;
- known limitations or safety requirements.

Read this index before creating a duplicate tool.
